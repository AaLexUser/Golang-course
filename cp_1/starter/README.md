## Алгоритм

Один проход по срезу продаж. Отменённые записи пропускаются до валидации.
Некорректные записи (пустой товар или категория, неположительное количество
или цена) увеличивают `InvalidSales` и не участвуют в расчётах. Для валидных
продаж накапливаются общая выручка, число единиц, выручка по категориям
(`map[string]int64`) и количество единиц по товарам (`map[string]int`).
Затем проходом по карте товаров выбирается лидер: при равном количестве
единиц побеждает лексикографически меньшее название. Исходный срез не
изменяется.

Сложность: O(n + p) по времени, где n — число продаж, p — число уникальных
товаров; O(c + p) по памяти, где c — число уникальных категорий.
